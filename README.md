# redes-seguridad
requisitos:
python 3.14

Ejercicio 1: Herramienta de Subneteo - Calcula la dirección de red, máscara, prefijo CIDR, broadcast, hosts útiles y el rango de direcciones IP a partir de una entrada en formato CIDR.   

Ejercicio 2: Prueba de Ping Individual - Envía un paquete de eco adaptado al sistema operativo (usando -n en Windows o -c en Linux/macOS) para comprobar si un host o IP responde.  

Ejercicio 3: Barrido de Red (Ping Sweep) - Explora una red completa en formato CIDR utilizando múltiples hilos en paralelo (ThreadPoolExecutor) para identificar rápidamente qué hosts están activos.  

Ejercicio 4: Escáner de Puertos TCP - Verifica mediante conexiones TCP si los puertos de servicios comunes (como FTP, SSH, HTTP, MySQL, RDP) se encuentran abiertos o cerrados.  

Ejercicio 5: Resolución DNS y Inversa - Traduce nombres de dominio a direcciones IP midiendo el tiempo en milisegundos y realiza una consulta de resolución inversa (registro PTR).  

Ejercicio 6: Verificador de Latencia TCP - Mide de forma repetitiva el tiempo de establecimiento de una conexión TCP a un puerto, calculando valores mínimos, máximos, promedio y porcentaje de pérdida.  

Ejercicio 7: Salud HTTP y Certificados TLS - Obtiene el código de estado HTTP y el tiempo de respuesta de un sitio, inspeccionando además el certificado SSL/TLS para calcular sus días restantes de validez. 

Ejercicio 8: Generador de Reportes HTTP en CSV - Realiza peticiones a múltiples URLs, mide sus tiempos de respuesta, maneja errores de sitios inexistentes y exporta un informe estructurado a un archivo reporte.csv.
